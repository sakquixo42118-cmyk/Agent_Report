## 当前与目标

0.1是固定工作流：输入文字→模型/规则提取任务参数→程序排序和按天分配。当前分支已增加模型选择工具→实际执行→结果回传→继续决策的循环。技术栈为Electron、Vue 3、TypeScript、better-sqlite3。

新版默认数据目录为`%APPDATA%/suishou-plan-agent/plan.db`，与0.1分开，不会自动导入旧任务和密钥。测试使用临时库；开发可用`SUISHOU_DATA_DIR`覆盖目录。

已接通：模型自主选择查询/澄清/草案/试排、确认记忆检索、耗时校准、后台消息，以及事项确认创建和计划确认保存。共享桥接已用模拟复习建议验证；后续接入真实作业问答、OCR校对、知识卡和复习内容。

**首版不用MCP**。内部工具函数→业务服务/DAO→SQLite；模型不能直接执行任意SQL。工具与接口的实际实现范围以阶段记录为准，完整方案中的目录/接口仍有待实现部分。

## Windows开发启动

准备Node.js 22 LTS（含npm）、Git。本次验证使用22.16.0；现有SQLite依赖在本机Node 24下安装失败，交接阶段请先使用22系列。首次安装需要联网下载依赖、Electron以及必要的原生模块资源；以下命令在本仓库根目录执行：

```powershell
npm ci
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm run dev
```

若Electron下载连接超时，可以在当前PowerShell窗口临时指定下载镜像，再重试安装（本次验证使用此方式）：

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
npm ci
```

构建后启动：

```powershell
npm run build
.\start-plan.bat
```

`start-plan.bat`依赖本机已安装node_modules和已生成out，不是免安装发行版。本仓库不携带运行时依赖或安装包。

如果原生SQLite模块ABI不匹配，可在已安装依赖后运行`npm exec electron-builder install-app-deps`，再构建。仍失败时检查实际Node/Electron版本和原始错误，不从他人电脑复制node_modules。

模型在应用“设置”中填写兼容接口地址、模型名和个人密钥；仓库不提供密钥。未配置时可人工批量预览或选择旧快速记录；自主助理会提示配置，旧快速记录仍可规则回退。不要提交个人数据库、截图中的账号信息或接口凭据。

当前分支加入课表与具体时段、确认记忆和个人校准。旧日期和新提取的截止候选需在任务“时间设置”确认；同类耗时反馈按该处的估时分组汇总。完成回顾只留今日消息，可忽略或关闭，不弹窗。完整统计和作业/OCR仍待实现，详细验证见阶段记录。

顶部默认“助理整理”，确认草案前不创建任务；批量输入同样先预览。修改草案后先保存；“待确认”和今日最近对话可找回记录。模拟作业入口在今日助理下方，明确使用固定测试数据。

第五阶段：今日可调整当天容量；日程可添加停补课、临时占用与前置关系。第六阶段：“统计”可回看近7日完成、冻结计划完成率、明确主动推迟与有效耗时误差；旧历史不回填。实际改期时可在确认卡选择用户原因；Agent能只读查询统计。课后主动检查、适度催办和运行期间提醒仍待下一阶段。

检查命令：`npm run typecheck`、`npm test`、`npm run build`。真实调用为可选项：设置本机`AGENT_TEST_KEY_FILE`后运行`npm test -- --live`；`--profile-live`、`--capture-live`、`--scheduling-live`、`--statistics-live`分别聚焦第三、四、五、六阶段真实场景，均保留全部隔离测试。仅发送合成测试用例、产生API用量，测试库结束时清空凭据，密钥文件不要加入仓库。
