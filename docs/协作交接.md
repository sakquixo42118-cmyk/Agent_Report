```text
src/main/agent/       共享Harness、工具注册/执行、Run（王浩宇）
src/main/drafts/      录入草案、来源/版本、复习建议桥接（王浩宇）
src/main/memory/      检索与来源/版本管理（王浩宇）
src/main/planning/    课表、估时、调度与校验（王浩宇）
src/main/study/       作业域工具、OCR适配器、学习记录（罗德金）
src/main/db/          共用连接和迁移总入口（王浩宇统筹）
src/shared/           共享类型/协议（王浩宇统筹，双方先对齐）
src/renderer/        今日/日程由王浩宇，作业/复习/OCR页面由罗德金
```

main/agent、main/drafts、main/planning、main/memory、main/feedback和main/statistics已在开发分支实现，main/study仍待开发。记忆字段与估时分组均使用分组原文，不加course:前缀。罗德金提供学习相关表结构/迁移草案，由迁移总入口统一编号（当前v11），不独立创建另一份数据库或复制模型密钥管理；作业自评不等同实际专注耗时，需分开存储。

## 4. 必须对齐的契约

- 工具返回`ok/data/errorCode/message/sourceRefs/stateVersion`；调用参数先运行时校验，再执行。
- UI通过preload/IPC启动Run，工具在主进程内部直接调用服务/DAO，不从模型请求任意SQL或本机路径。
- 只读查询按范围返回必要信息；写入使用可信授权、版本检查、短事务和幂等键。
- 作业建议只产生任务草案（题目/知识卡证据ID、内容、估时、窗口），用户确认后由规划侧建任务和排期；返回实际任务ID防重复。
- OCR使用已上传imageId，确认校对稿后分析。原图、识别稿、确认稿保留修订关系。
- 模型分析、用户自评、确认事实、算法统计各保留来源，不能混为确定的个人画像。
- 测试使用独立数据；假接口/回放与真实模型结果分别记录。

可直接使用registerTool/registerScene与startSceneRun；复习草案通过registerReviewProvider/startReviewProposal对接。builtin study_mock是固定数据测试，不能作为真实作业模型。新确认种类仍需共享类型、处理器和UI卡片；注册表不会自动生成页面。具体调用示例、错误及同步接口限制见接入契约。

## 5. Git协作方式

各自clone本仓库。共享开发分支`feature/planning-agent`已存在，main仍为0.1。罗德金后续应从双方确认的共享提交创建`feature/study-assistant`，不要直接从main创建而遗漏前几阶段能力；study分支当前尚未创建。接口收尾计划见[需求核对与后续阶段安排](需求核对与后续阶段安排.md)。

```powershell
git fetch origin
git switch feature/planning-agent
git pull --ff-only origin feature/planning-agent
git switch -c feature/study-assistant
```

小步提交，一次一个明确改动；合并前说明改了什么、接口变化、验证方法和未完成项。共享迁移/工具注册/类型变更先对齐，避免分别改好再整段覆盖。不得提交个人API Key、数据库、node_modules或生成的安装包。
