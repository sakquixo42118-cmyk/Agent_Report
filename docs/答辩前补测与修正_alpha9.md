# 答辩前补测与修正：0.2.0-alpha.9

日期：2026-11-10。接收分支：feature/planning-agent；数据库继续使用统一v15，没有新增迁移。本轮修复录屏暴露的问题，补测已实现功能；未把原方案的全部设想改写为已完成。

## 修复与具体实现

| 问题 | 修正 | 证据 |
|---|---|---|
| 模型把“这周四”映射到错误日期 | grounding.ts按本地日历计算本周/下周和准确星期；新增resolve_date只读工具，系统提供紧凑日期对照 | 跨周、跨年、非法日期、日期与星期冲突测试；真实模型查询本周四 |
| 为提问凑选项，编造库外任务 | 新增ask_task_selection，只接受已读取的真实taskIds，程序从最新任务生成按钮；同名加编号区分，任务变化要求重查 | 未读、同名、无效ID、过期读取与真实模型测试 |
| 把“第一节课”自行变成具体钟点 | 记忆草案明确钟点需能在用户消息、可信读取结果或原确认事实中找到依据；被拒后模型可以保留原话/追问 | 中英文时刻归一、无依据拒绝、真实模型记忆草案 |
| 只拿任务名搜记忆，空查后漏掉值班事实 | 提供最多12个分组/名称主题索引，空查询也返回主题供模型改写关键词；正文仍通过search_memory按需读取 | 不注入全部正文、过期主题排除、主题重查与真实模型来源命中 |
| 用户要求依据记忆回答，模型却只看课表 | 对明确“记住的/已确认记忆”请求核验检索执行证据；普通请求仍由模型决定是否检索 | 结束前无检索会返回可纠正观察；真实模型在同轮补读后回答 |
| 口头声称已实际试排、或用追问绕过试排 | 对明确“实际试排”的请求核验工具执行；唯一任务信息齐备时不得用口头冲突判断替代算法；多候选/信息不足仍可澄清 | DAO与实际preview_plan用例；真实不可行场景与独立定向验证 |
| 试排成功后只口头问“是否确认”，没有确认卡 | 对明确要求直接propose_plan/展示确认卡片的请求检查实际卡片；可行结果需交可信确认链路 | 可行预览→卡片校验→真实作业桥接测试 |
| OCR结束时成功提示跟着卡片消失 | 独立保留结果通知；部分识别/取消保留可续传范围，从首个缺页继续；增加公式/代码原页核对提示 | 原生界面1—2页得到2/3，再识别第3页得到3/3，结束提示仍在 |
| MAPE名称与分母口径不一致 | 改为平均\(\lvert预计-实际\rvert/实际\)×100%；UI与工具定义同步，仅统计有效正耗时 | 独立手算、多来源分组、真实统计查询；原生界面60估时/90实际得到33.3% |
| 催办照抄任务标题中的相对时间 | 后台上下文提供当前剩余分钟与截止状态；明确倒计时与真实截止冲突时拒绝发布，回传观察供模型同轮纠正 | 标题相对时间失效、工作量非倒计时、错误消息不发布且可纠正测试 |

这些校验检查事实来源、用户明确要求的执行证据与写入协议，不规定所有请求的固定工具顺序。模型仍决定查哪些任务/记忆、是否澄清、如何处理不可行结果；程序保证不能以口头答复冒充执行或用户确认。钟点与倒计时校验是有明确范围的护栏，不是对所有自然语言真实性的通用判定器。

## 测试结果

- 完整`npm test -- --live`：**253项通过，包含234项隔离测试和19项真实千问场景**。类型检查与构建通过。
- 真实场景涵盖原有查询、调级、歧义、排班/不可行、记忆、校准、后台回顾、录入、模拟作业桥接、复杂约束、统计、课后检查和风险建议，以及本轮新增日期、记忆事实、主题检索、真实任务选项。
- 调试中确实出现过失败：旧统计测试仍期待旧分母；新增真实测试误放在凭据清理之后；真实模型遗漏执行/确认/检索。分别修正口径、测试顺序与执行协议，最终在同一完整测试调用中通过。通过数量不是首次通过率、覆盖率或模型准确率。
- 真实调用只用隔离测试库与合成任务，结束后清空该测试库凭据。日志不输出密钥。
- `npm test -- --live --hardening-live`可聚焦本轮4项真实模型行为；仍执行全部隔离测试。原有profile/capture/scheduling/statistics/attention专项参数继续有效。真实测试进程预算为10分钟，单次Agent/后台运行预算未因此放宽。

## 已实现功能覆盖与仍未覆盖项

- 你负责的录入/草案、记忆/反馈、截止分离、课表/空档/排班、停补课/临时占用/单日容量/依赖、统计账本、主动检查/提醒均有自动化验证；主要链路有真实模型和实机证据。停补课、依赖、锁定等每种边界未全部单独录屏。
